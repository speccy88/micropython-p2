# P2 audit checklist

The audit compared the sources distributed at `dda022a0c` with the full Edge firmware built from `ee618817c`. The latter runs at 160 MHz and exposes 32 MiB of explicit external storage. Each physical result identifies its image digest. [Released binaries and source](firmware/manifest.json) · [Matched performance measurements](validation/PERFORMANCE.md)

| Finding | Fix, evidence or remaining requirement |
| --- | --- |
| Inherited Actions and email noise | Removed 27 upstream workflows and disabled their existing definitions through the repository API. The always-reporting P2 host gate covers formatting, spelling, package, bytecode and integrity checks. Relevant shared changes run one native Unix subset. Pages deploys installer changes. Toolchain builds and the three-platform kit diagnostic are manual. The P2 size report replaces upstream PR comments; users install stock mpremote. [Definitions, failed-job logs and dispositions](validation/CI.md) |
| ELF/compiler corruption | Verified original kit.1 asset damage, recovered all four binary blobs against the original SHA-256 values, fixed binary attributes and compiler executable mode, and added checkout/archive verification to the starter builder. [Byte counts, checksums and verification commands](validation/STARTER.md) |
| VM, compiler and ABI | Rechecked physical varargs, aggregates, memory transfers, arithmetic, bool/flags and NLR/setjmp with the patched compiler. Repeated Edge VM tests cover exceptions, recovery after stack and heap exhaustion, and GC. Maintain the compiler overlay and `-Werror=vla`. The register/unaligned root fixture and collision tests have their own executable or script. [ABI receipt](validation/audit-foundation.json) · [VM and serial receipt](validation/audit-final-edge.json) · [Roger Loh and compiler regressions](toolchain/roger-comparison.md) |
| Test selection and serial reliability | The kit.1 reference suite had 573 passes, 83 device-requested skips and 42 configuration exclusions in 698 upstream files. Its report enumerates the source guards. The replacement has separate exact-output, raw paste, Ctrl-C and repeated raw reset results. Retain the full upstream runner for longer sessions. [Historical upstream selection](validation/upstream.json) · [Targeted replacement checks](validation/audit-final-edge.json) |
| Speed and hub heap | Measured isolated VM object optimization, direct dispatch, rolling GC scan, compressed errors, cache hits and QPI bursts. The selected full Edge image saves 468 image bytes and gains 472 bytes of GC arena. Five-run tables give speed, spread, stack samples and critical-section latency. Global clock and feature profile stayed fixed. [Controlled comparisons](validation/PERFORMANCE.md) |
| PSRAM and larger programs | Verified all 32 MiB, bounds, alignment, overlapped data movement, cache flush and buffer borrow order on hardware. The two-page cache is 512 bytes; the measured array uses 880–928 retained hub bytes across two harnesses. Peak transient allocations depend on the caller. Bytecode stages run from external filesystems, one live stage at a time. General executable overlays need return/relocation handling; external Python objects additionally need pointer and GC support. [Final sweep and boundary checks](validation/audit-final-edge.json) · [Execution and memory cost model](drivers/MEMORY.md) |
| Workers and native drivers | The experimental worker profile adds bounded mailbox access to rooted P2D1 HUBEXEC services. The primary cog retains electrical ownership, construction and stop. VM cogs share the GIL. Verified contended requests, GC, denied lifecycle requests and stale-handle rejection. Full Edge PSRAM/storage access from Python workers requires a service and ownership protocol. [Thread contract](VM.md#threaded-profile-and-native-services) · [Service test](validation/audit-threadservice.json) · [Timeout and cog recovery](validation/audit-hubdriver.json) |
| Peripheral completeness | Native UART loopback, eight SoftSPI mode/order combinations, PWM-to-capture and ADC internal references passed on the P2. Host I²C tests model ACK, partial NACK, repeated START, read and stretching/timeout with the actual transfer engine. Deferred edge counts use one Smart Pin and a scheduled VM timer. Test an actual I²C target, SPI display, MIDI instrument, strip, servo and quadrature encoder using the published pin assignments; calibrated ADC/DAC values and timing margins need a reference and scope. [Bus contracts](bus/README.md) · [Wiring](drivers/README.md) · [On-board waveform results](validation/audit-final-bench.json) |
| Storage, startup and recovery | FAT write/modify/flush/reopen and dirty-file reset passed on the designated SD card. Friendly reset ran boot.py then main.py and raw mode bypassed both. The 4,096-byte NOR sector at 0xFFF000 was backed up, erased, programmed, verified and restored byte-for-byte. Boot-region SPI programming is a separate acceptance. Power-cycle tests require physical power control and correct ROM straps. [SD/startup receipt](validation/audit-sd.json) · [NOR receipt](validation/audit-nor.json) · [Recovery and boot procedure](storage/ACCEPTANCE.md) |
| Configurable stress | The board workload combines serial round trips, allocations and GC, PSRAM read-back, LittleFS2 writes, a timer and an independent native worker. Each sample records heap and both worker counters; the host checks reset recovery. Use `--seconds` to select the duration. Python worker contention is covered on the separate threaded image. [Runner](tests/sustained.py) |
| Packages, installations and integration | Serial file editing on the P2, 31,250-baud MIDI messages, USB-host-assisted HTTP, and deferred rising-edge delivery complement mpremote/mip, ViperIDE and external arrays. WS2812 timing was captured on adjacent Smart Pins. Historical sensor/display checks use recording buses. Windows tested the physical USB board; the Linux compiler ran under WSL. [Practical tutorial](packages/APPLICATIONS.md) · [Compatibility and remaining capabilities](packages/COMPATIBILITY.md) |
| P2 ecosystem, emitters and delivery | Retain Roger Loh, TinyGo/P2, Team Oz and Total Spectrum/Rayman source credit. VGA, USB HID and SID/audio synthesis still need native services, timing/resource budgets and connected peripherals. Native/Viper decorators and executable native .mpy need a P2 emitter, relocation/entry ABI, root and unwind handling, and target acceptance. P2D1 loads an independently assembled service.
